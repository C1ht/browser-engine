⚡ bolt

A tiny from-scratch browser engine built for raw speed.

Try it

Type a URL or a local file path into the address bar (Ctrl+L), or try:

about:features — flexbox, grid, floats, positioning   about:js — JavaScript demo   about:stress — a 1,500-section synthetic page (~40k nodes)   example.com   Hacker News   DuckDuckGo Lite   text.npr.org

Pipeline

Parse

Single-pass byte tokenizer with SWAR memchr, arena DOM, interned atoms.

Style

Bucketed rules, ancestor bloom filter, one linear pass over the arena.

Layout & Paint

Block/inline/table layout, cached advances, banded multi-threaded raster.

Not (yet) supported

  1. Animated images (first frame only), SVG filters/masks, per-character font fallback across unicode-range subsets
  2. JS modules, custom elements, shadow DOM, canvas, WebSocket, text selection, <select> drop-downs; generators run eagerly, so infinite ones stop at 100k values
  3. Transforms, filters, animations, right-to-left text
bolt is a learning-sized engine: ~20k lines of Rust, two dependencies (window + glyph rasterizer).
